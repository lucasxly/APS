## 🚀 Sobre o AcessMarket

### 🎯 Objetivo
Desenvolver um aplicativo mobile que utiliza inteligência artificial para identificar produtos em supermercados, proporcionando autonomia e acessibilidade para pessoas com deficiência visual durante suas compras.

### 👥 Público-Alvo
- **Pessoas com deficiência visual:** Identificação de produtos através da câmera do smartphone
- **Voluntários:** Sistema de ajuda visual via chamada de vídeo

### 🛠️ Tecnologias Utilizadas
- **Plataforma:** Android
- **Linguagem:** Kotlin
- **IDE:** IntelliJ IDEA
- **Banco de Dados:** MySQL
- **Arquitetura:** MVVM (Model-View-ViewModel)
- **Conectividade:** 5G/4G/3G/2G

## 🎨 Funcionalidades Principais

### Reconhecimento de Produtos:
- Identificação de produtos através da câmera do smartphone
- Processamento de imagem com inteligência artificial
- Retorno de informações por áudio (marca, tipo, características)

### Sistema de Ajuda:
- Chamadas de vídeo ao vivo com voluntários
- Interface acessível para pessoas com deficiência visual
- Sistema de avaliação pós-chamada

### Gerenciamento de Compras:
- Lista de produtos identificados
- Controle de itens já selecionados
- Prevenção de duplicidades

## 🏗️ Arquitetura do Sistema

### Padrão MVVM:
- **Model:** Manipulação de dados, regras de negócio e lógica do aplicativo
- **View:** Interface visual e elementos interativos
- **ViewModel:** Intermediário entre View e Model, lógica de apresentação

### Componentes Especializados:
- **BarcodeModel:** Identificação de códigos de barras
- **AIModel:** Reconhecimento de produtos via IA
- **ProductListModel:** Gerenciamento da lista de produtos

O trabalho atende plenamente aos requisitos da APS e representa uma solução tecnológica inovadora para inclusão social de pessoas com deficiência visual.
