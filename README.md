# Atividades Práticas Supervisionadas — UNIP

Repositório que reúne todos os projetos desenvolvidos durante os 8 semestres do curso de Ciência da Computação na Universidade Paulista (UNIP). O objetivo é documentar e preservar as soluções criadas nas Atividades Práticas Supervisionadas (APS), abrangendo diferentes linguagens, tecnologias e temas.

## Estrutura do Repositório

Cada pasta representa um semestre do curso, contendo o respectivo projeto APS, sua documentação e código-fonte. Veja um resumo de cada semestre:
