# APS - 4º Semestre

Este repositório reúne os arquivos da Atividade Prática Supervisionada (APS) do curso de Ciências da Computação (disciplina: Estrutura de Dados Turma: CC4A33).

Resumo rápido
- Objetivo: armazenar o código-fonte e documentos relacionados à APS.
- Conteúdo principal: implementações em C e documentação.

Estrutura do repositório
- `main.c` — arquivo-fonte principal em C.
- `LICENSE` — arquivo de licença do projeto.

Pré-requisitos
- Um compilador C (por exemplo, `gcc` via MinGW no Windows ou `gcc` no Linux/macOS).

Como compilar
- Windows (PowerShell/CMD, com MinGW ou equivalente):

	`gcc main.c -o main.exe`

	Em seguida execute:

	`./main.exe`

- Unix / Linux / macOS:

	`gcc main.c -o main`

	Em seguida execute:

	`./main`
